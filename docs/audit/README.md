# 공개 전 감사 기록

검사 기준: 2026-09-28, 초기 커밋 `411f736b9bf479629cdaeb18b90a69e9c249133d`.
수정 전에 추적 파일 1,650개(약 815 MiB), 로컬 모든 ref의 도달 가능한 커밋 1개를 확인했다.
shallow 저장소가 아니지만, 원래 개발 GitLab의 과거 이력이 이 복사본에 포함되어 있다는 뜻은 아니다.
원격 fetch, push, merge, 이력 재작성은 하지 않았다.

## Critical

- 패턴 검사에서 API 키·토큰·비밀번호·SSH 개인키로 확정된 항목은 없었다. 미탐 가능성이 있으므로 무조건 안전하다는 보증은 아니다.
- 기존 커밋에는 개인 경로·장비 IP·팀원 정보가 남는다. 이번 변경은 작업 트리 정리이며 이력에서 삭제한 것이 아니다.

## Required

- 개인 경로, 장비 사설 IP, 직접 작성한 패키지의 개인 연락처와 팀원 목록을 공개용 기본값으로 바꾼다.
- 노트북 저장 출력을 비우고 데이터 경로를 예시 상대경로로 바꾼다.
- 루트 README, 하위 핵심 README, GitLab Wiki용 문서를 실제 구조와 구현 기준으로 작성한다.
- FreeRTOS/500 Hz 설명, 존재하지 않는 디렉터리·실행 명령 등 확인된 불일치를 고친다.
- 추적된 관제 ELF 실행 파일 2개를 제거하고 소스 빌드 방법을 제공한다.
- `.env` 변형, 인증서/키, 빌드·로그·캐시의 재유입을 방지한다.
- Blender·FreeCAD 원본과 외부 TorchScript 모델의 내장 로컬 경로는 바이너리 훼손을 피하기 위해 수동 정제 대상으로 남긴다.

## Optional

- 모델, 학습 결과 그림, CAD 합계가 크다. 재현 자료를 임의 삭제하지 않고 보존한다.
- 현 `.gitattributes`는 일부 CAD 확장자만 LFS 대상으로 지정한다. 현재 모델 전체가 LFS 관리된다는 설명은 삭제한다.
- 폴더 재배치, 기능 개선, 프로젝트 운영 규칙 추가는 범위 밖이다.

## 검사 방식과 한계

모든 추적 파일의 바이트, UTF-8 텍스트의 경로/IP/자격증명/내부 도메인 패턴,
ZIP 형식 모델 컨테이너의 50 MiB 이하 멤버, 패키지 메타데이터, 노트북 소스·출력을 확인했다.
바이너리는 경로·키 시그니처 검사를 했으며 이미지 OCR이나 Blender/CAD 렌더링 검수는 하지 않았다.
라이선스의 저작자 및 외부 라이브러리 attribution은 개인정보 치환 대상에서 제외했다.
원격 URL 및 Git 작성자 메타데이터는 로컬에 유지했으며 외부 서비스에 접속하지 않았다.
기준 커밋 하나의 파일 트리가 검사한 수정 전 작업 트리와 동일하다.
세부 발견 위치와 용량 목록은 `baseline.json`에 있으며 민감한 실제 값은 담지 않는다.

최종 수동 확인 항목은 `../wiki/Release-Checklist.md`를 참고한다.

## 문서 링크 추가 점검

실험 보고서의 잘못된 이미지 상대경로 35개를 수정하고, 누락된 recovery 이미지 33개는 미포함으로 표시했다. 전역 경로 문서의 누락 이미지도 실제 포함된 예시로 바꿨다.
